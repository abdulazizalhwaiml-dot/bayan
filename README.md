# بيان — المحاسبة بالصورة والتجربة

هذه الحزمة تحتوي على ملفات الموقع والصور، وجاهزة للنشر على GitHub Pages.

## محتويات الحزمة
- index.html: الصفحة الرئيسية.
- style.css: التصميم والألوان والتجاوب مع الشاشات.
- app.js وlab.js: الشروح والتجارب التفاعلية.
- images/: الصور والرسوم بصيغة SVG.
- .nojekyll: إعداد للنشر المباشر على GitHub Pages.

## الرفع إلى GitHub
1. فك ضغط الحزمة.
2. أنشئ مستودعًا عامًا باسم bayan أو اسم تختاره.
3. ارفع الملفات ومجلد images إلى جذر المستودع، بحيث يكون index.html في الجذر.
4. من Settings ثم Pages اختر Deploy from a branch، ثم main والمجلد / (root)، واضغط Save.
5. سيظهر رابط الموقع في صفحة Pages.

## تجربة الموقع محليًا
افتح index.html في متصفحك، مع إبقاء ملفات JavaScript وCSS ومجلد images في أماكنها.

الموقع لا يحتوي على نظام حسابات مستقل؛ يُحفظ تقدم الدروس واللغة في المتصفح.
